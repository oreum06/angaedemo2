# Angaegol Visual-First Codex Package v2
This revision supplements the existing VN PRD with a strict visual specification and the user's actual village background reference.

## Start
1. Extract ZIP into an empty project folder.
2. Add official character reference sheets to `assets/reference/characters/` (not bundled).
3. Ask Codex: "Read AGENTS.md and VISUAL_DIRECTION.md first. Build only Phase 1, use assets/reference/village_visual_target.png, take a 1920x1080 screenshot, and stop for visual review. Do not use generic placeholder UI in the acceptance screenshot."
4. After approving screenshot, proceed to Phase 2.

## Contents
- VISUAL_DIRECTION.md — highest-priority visual rules and visual QA gates
- GAME_PRD_VN.md — existing story/game requirements
- ART_GUIDE.md — earlier art specification (VISUAL_DIRECTION.md wins on conflicts)
- STORY_DATA_SAMPLE.json — dialogue example, not full 15-minute script
- AGENTS.md — staged Codex execution instructions
- assets/reference/village_visual_target.png — user-provided background image

NOTE: Codex can implement layout, UI, transitions, and asset integration, but cannot guarantee matching official illustrations without the original character assets and appropriate extracted sprites.
